# House Price Prediction Using Machine Learning
## Overview
This project predicts house prices using Machine Learning on the Boston House Price dataset. It includes data preprocessing, exploratory data analysis, feature correlation, model training, and performance evaluation.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

## Project Workflow
- Data Loading
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Train-Test Split
- Model Training using XGBoost Regressor
- Model Evaluation (MAE, MSE, RMSE)
- House Price Prediction

## Results
The model was trained and evaluated using regression metrics to predict house prices based on different housing features.
